# Food: Label Desk

Owner-selected direction B, 12 November 2026. Nutrition comparison leads. Food and recipes share one shell.

Use @saas-maker/ui 0.1.33 for every reusable UI component, semantic theme roles and bundled Geist typography. The workspace header is #19242b, the canvas #f4f5f6, data surfaces white, primary text #1b252b, secondary text #52606b, borders #d7dde1, and source attention #925000. Display type uses Geist at 30–42 px with -0.035em tracking; body is 14 px. Numbers use tabular figures. Controls have 44–48 px touch targets and 6–8 px radii.

The catalog is a dense desktop nutrition ledger. At 1000 px it becomes labelled records with the same five macros and protein-density hierarchy. Search and filters precede the data. Recipe results use compact source-linked rows, with serving macros and expandable ingredients. Avoid oversized marketing counters, decorative status rings and competing recipe branding.

Missing data, source conflicts, estimates and observation dates remain readable. Error states include retry; empty filters can be reset; product details contain focus and support Escape. Keyboard focus, text selection, caret and scrollbar colors derive from the palette. Shared library controls retain native semantics.

The source-quality page distinguishes source records from canonical products, numeric checks from label checks, and selected examples from a population accuracy estimate. Product images are source material, not proof of identity; suppress exact known mismatches.

Shared Sheet, Dialog and AlertDialog own modal focus/dismissal. Page code supplies data, content and responsive composition; do not recreate controls, cards, feedback or modal behavior with plain elements. Run the UI ownership audit with the normal check.
